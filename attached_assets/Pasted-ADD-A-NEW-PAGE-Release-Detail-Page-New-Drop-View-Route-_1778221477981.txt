## RELEASE DETAIL PAGE LAYOUT — /releases/:slug

Pull the correct release from the releases array using the URL slug param (useParams from React Router).

---

### SECTION 1 — BREADCRUMB
- Path: Home › [Artist Name] › [Release Title]
- Each segment is a clickable link (Home → /, Artist → /artists/[artistSlug], current page highlighted in #E8FF00)
- Bebas Neue, small, gray with yellow active
- Animate in from top on load (GSAP, opacity 0 → 1, y: -10 → 0, delay 0.2s)

---

### SECTION 2 — RELEASE HERO (two-column split layout)

**LEFT COLUMN (album art side):**
- Large square album artwork image — use dark moody picsum image with release title overlaid in large Bebas Neue
- The album art has a subtle yellow outer glow (box-shadow: 0 0 60px rgba(232,255,0,0.2))
- On page load: album art slides in from left (GSAP x: -80 → 0, opacity 0 → 1, duration 0.9s, ease: power3.out)
- Below the album art: mini audio player UI (purely visual/CSS — no actual audio required):
  - Track name on left (current track from tracklist[0])
  - ⏮ ▶ ⏭ controls in yellow, centered
  - "00:00 / 03:29" time display on right
  - Thin yellow progress bar (30% filled as default state)
  - This entire player is dark card (#161616), 1px #222 border, rounded corners

**RIGHT COLUMN (release info side):**
- Release title: Bebas Neue, massive (5xl–7xl), white, animate in from right (GSAP x: 80 → 0, opacity 0 → 1, delay 0.3s)
- Below title: genre tag pills in yellow (#E8FF00 background, black text, small Bebas Neue, border-radius: 4px)
- Description paragraph (DM Sans, #888, 1rem, line-height 1.7) — real text from releases data
- Metadata block (DM Sans, small):
  - "Label" — value: 1NJAMAICAMUSIC (yellow)
  - "Artists" — value: artist name (white, clickable → artist page)
  - "Release Date" — value: date (white)
  - "People" — value: comma-separated names (white)
- Each metadata row: label in #555 gray, value in white, separated by thin line
- Metadata block fades in with stagger (GSAP, each row 0.1s delay apart)

---

### SECTION 3 — TRACKLIST

- Heading: "TRACKLIST" — Bebas Neue, 2xl, white, yellow left-border accent (4px solid #E8FF00)
- Each track row:
  - Track number: yellow, small, monospace (#01, #02, etc.)
  - Track name: white, DM Sans, medium weight
  - RIGHT side: either "BUY TRACK ↗" button (yellow text, outlined, small pill) OR "FREE DOWNLOAD ↓" button (green #39FF14 text, outlined, small pill)
  - Hover: entire row background shifts to #1a1a1a, track name turns yellow
  - 1px #222 divider between rows
  - On scroll into view: rows animate in from bottom, stagger 0.08s each (GSAP ScrollTrigger)
- BUY TRACK links open external URL (# placeholder for now)
- FREE DOWNLOAD links trigger a toast: "Redirecting to download..." in yellow top-right

  - Each links to streamingLinks[platform] from data

### SECTION 5 — OFFICIAL VIDEO

- Heading: "OFFICIAL VIDEO" — Bebas Neue, 2xl, white, yellow border
- Full-width (max-width: 900px centered) dark container
- YouTube thumbnail image (use picsum dark image as fallback) with:

- Yellow hover glow on cards
- "VIEW ALL [ARTIST] RELEASES →" link → routes to /artists/[artistSlug]
- Cards animate in from bottom on scroll, stagger 0.1s

- Right: "BOOK NOW →" button — yellow filled, black text, large, pill-shaped
