Build a full multi-page music label website for "1NJAMAICAMUSIC" — a Jamaican music label representing artists Hintell, Dark Koko, Swazz, and Mee$ch operating under the "Rawtracks" brand. This is a production-ready, animated, dark cinematic storytelling website. Every section must be filled with real content — NO placeholder text, NO lorem ipsum, NO empty states anywhere.

---

## TECH STACK
- React 18 + Vite
- React Router DOM v6 (multi-page routing)
- TailwindCSS v3
- GSAP + ScrollTrigger + SplitText (for all animations)
- Framer Motion (for page transitions)
- Lucide React (icons)
- Google Fonts: "Bebas Neue" (display/headings) + "DM Sans" (body)

## GLOBAL DESIGN RULES
- Background: #0A0A0A (near-black) throughout ALL pages
- All heading text: Bebas Neue, uppercase, tracked wide
- Body text: DM Sans, #F5F5F5 or #888888
- Accent color: #E8FF00 (neon yellow) — used for highlights, underlines, CTA buttons, active states
- Secondary accent: #39FF14 (neon green) — used for the logo only and subtle glows
- Buttons: Black background, yellow border + text, hover fills yellow with black text. Pill-shaped (border-radius: 999px) or sharp rectangle — alternate per section.
- Section dividers: thin 1px #222222 horizontal lines or yellow dashes
- Cards: #161616 background, 1px #222222 border, subtle yellow glow on hover (box-shadow: 0 0 20px rgba(232,255,0,0.15))
- Custom cursor: large yellow circle outline that follows mouse with slight lag (CSS + JS)
- Grain overlay: add a subtle SVG noise texture fixed over the entire site at 4% opacity
- Smooth scroll: use Lenis or CSS scroll-behavior: smooth
- All images: use high-quality music/Jamaican-vibe placeholder images from https://picsum.photos with dark overlay filters until real images are swapped

## ANIMATIONS — IMPLEMENT ALL OF THESE

1. **Page load**: Logo + nav links fade in from top, hero text characters animate in using GSAP SplitText (chars from bottom, staggered 0.03s)
2. **Page transitions**: Framer Motion — yellow horizontal bar wipes across screen left-to-right on route change, then reveals new page
3. **Scroll reveals**: Every section heading uses GSAP ScrollTrigger — text blurs in from opacity 0, filter blur(20px) → blur(0), translateY(40px) → 0, once: true
4. **Parallax hero**: Hero background image moves at 0.5x scroll speed (GSAP ScrollTrigger scrub)
5. **Artist cards hover**: image scale 1.05, card border color → yellow, smooth 0.3s ease
6. **Marquee ticker**: CSS infinite scroll animation, two instances side by side for seamless loop
7. **Number counter**: Stats section numbers count up (0 → final value) when entering viewport — GSAP to() with snap
8. **Cursor**: Custom yellow circle cursor (30px outline), follows mouse with 0.1s lag using requestAnimationFrame
9. **Album art marquee rows**: Two rows of album art, one scrolling left, one scrolling right (CSS animation), hover pauses the row
10. **Nav dropdown**: GSAP opacity + translateY reveal on hover, smooth 0.2s
11. **Mobile menu**: Full-screen black overlay, nav items stagger fade-in from left, GSAP timeline
12. **Form focus states**: Yellow glow border-color transition on input focus
13. **Accordion**: GSAP height animation from 0 to auto for FAQ items
14. **Toast notifications**: Slide in from top-right, auto-dismiss after 4s
